Overview

What is it?

A Model Context Protocol server that bridges live AppDynamics observability data with AI assistants — turning natural language into production insights.

⚡
Model Context Protocol
An open standard that lets AI tools call external data sources. This server registers 23 tools Claude or Cursor can invoke to query live AppDynamics data in real-time.
📊
AppDynamics Integration
Connects to AppDynamics SaaS REST and RESTUI APIs with OAuth2. Covers applications, metrics, transactions, health, snapshots, dashboards and more.
🤖
AI-Native Observability
Ask "What's degraded in production?" and get live data, automated root-cause analysis, and auto-generated monitoring dashboards in a single conversation.
